# Corrección del inicio de sesión

Para una base existente, ejecutar database/actualizar_claves.sql una sola vez en HeidiSQL. Solo modifica las cuatro claves de prueba que todavía están en texto plano. No elimina registros. No ejecutar nuevamente siges.sql ni datos_prueba.sql sobre una base existente.

Para una instalación nueva, usar siges.sql y datos_prueba.sql (ya contiene hashes).

Cuenta local de prueba: admin@siges.com / Admin123. Cambiar las claves de prueba antes de publicar el sistema.
